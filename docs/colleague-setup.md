# 用 Codex 查小程序短剧数据（一次性配置）

这份文档给产品/运营同事。配好之后，你只要在 VS Code 的 Codex 里用中文提问就行。

## 一、拿到两样东西

找 weappctl 的维护人要：

1. 服务地址（形如 `http://10.0.0.23:8787/`，示例地址，以实际给你的为准）
2. **你自己的** token（一串十六进制字符，不要和别人共用）

## 二、改一次配置

1. 打开 `~/.codex/config.toml`（macOS/Linux 都在这个路径；VS Code 的 Codex 插件和 CLI 共用这一份配置）。
2. 把下面这段贴到文件末尾，把地址和 token 换成你自己的：

```toml
[mcp_servers.weapp]
url = "http://10.0.0.23:8787/"
http_headers = { "Authorization" = "Bearer 把这里换成你的token" }
enabled_tools = ["list_dramas", "published_dramas", "get_drama"]
```

3. **完全退出并重启 VS Code**（不是重新加载窗口，是退出进程）。
4. 在 Codex 里问一句"现在有多少短剧上架"。如果第一次弹出一个授权/信任提示，点允许并勾选"记住"，之后不会再问。

## 三、可以这样问

| 你想知道 | 直接这样问 |
| --- | --- |
| 现在有多少短剧上架 | 现在有多少短剧上架？在架的是哪些？ |
| 有哪些剧被下架了 | 有哪些短剧被平台下架了？ |
| 审核情况 | 有多少部在审核中？有多少部被退回修改？ |
| 某部剧的状态 | 《好梦过长沙》现在是什么状态？（它会先查列表拿到 id，再查详情） |
| 制作方/编剧维度 | 制作方是 XX 的剧有哪些？ |

回答里出现的状态词含义：

- `in-review` 审核中、`returned` 退回待修改、`rejected` 终审不通过、`approved` 审核通过、`taken_down` 被平台下架。
- **`approved` 不等于已上架**：审核通过只是"有资格上架"。问上架数量请明确说"上架/在架"，别看 `approved` 的数字。

## 四、常见问题

**工具列表里没有 weapp / Codex 说找不到工具**
配置写错了位置或没重启 VS Code。确认是 `~/.codex/config.toml`（不是项目里的 `.codex/`），并彻底重启 VS Code。

**提示连不上 / 超时**
先确认你在办公网或已连 VPN（这个服务只在内网可达），然后找维护人确认服务地址有没有变。

**提示 401 / unauthorized**
token 写错了，或者已被吊销。检查 `config.toml` 里 `Bearer ` 后面那一串有没有多余空格或引号；不对就找维护人换一个。

**数字和别处对不上**
"上架数"和"审核通过数"是两个不同的数字，问法决定答案；另外数据是实时查微信的，和早上看到的可能不一样。

**想让 agent 帮忙删掉某部剧**
这个服务**没有**删除能力，别让它去调别的接口。删除要走维护人（本机 CLI 上的 `delete-media` 是不可恢复的）。

**token 能贴到群里吗**
不能。它等同于你的身份，泄漏了别人就能用你的名义查数据；发现泄漏立刻找维护人吊销重发。
