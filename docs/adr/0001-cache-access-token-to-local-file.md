# 将 access_token 缓存到本地文件

微信 `access_token` 换取接口有严格频率限制，且官方文档明确要求调用方自行缓存、不要每次调用业务接口前都重新换取。weappctl 因此在每个 Profile 目录下（`~/.weappctl/cache/<profile>.token.json`）以明文 JSON 缓存 access_token 及其过期时间，下次调用时若未过期直接复用，否则才重新换取。

备选方案是每次调用都现换（简单但会撞频率限制，且拖慢命令执行）、或改用系统 keychain（更安全但引入平台相关依赖，且 CLI 常运行在无 keychain 的 CI 环境）。选择明文文件缓存是在"不撞频率限制"和"不引入平台依赖、CI 环境也能用"之间的折中；风险是 token 文件本身是敏感信息，依赖文件系统权限（写入时设为 0600）而非额外加密。
