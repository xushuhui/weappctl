# 破坏性命令不加客户端确认

`delete-media`（`deleteMedia`）是 weappctl 第一个会造成不可逆数据丢失的命令，此前接入的都是只读接口。选择让它和其它命令一样直接执行、不加交互式确认提示、也不要求额外的 `--yes`/`--force` 标志，理由是保持 CLI 可脚本化——任何默认拒绝执行或需要交互输入的设计都会在非交互环境（CI、脚本管道）中意外中断或需要绕过，而 weappctl 本身就是薄封装微信服务端 API，不承担比 API 本身更强的误操作保护。风险由调用方自行承担，与直接调用微信 API 的风险等价。这条策略同样适用于未来任何新增的破坏性命令。
